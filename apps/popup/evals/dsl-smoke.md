# Stable-option authoring smoke sample

On October 10, 2026, a fresh Sol agent received only the frozen tool description/schema in `dsl-authoring.json` and a scenario: investigate unwanted initial selection and expansion, offer compatible concrete tests for initial expansion, hide/reopen behavior and submitted values, and allow inspection of a proposal without selecting it. No tests had been run in the scenario.

`dsl-smoke.json` is its unedited tool invocation. It uses stable option IDs, inline children, unselected recommendations, an independent disclosure, and a cross-branch shared follow-up. The schema test validates it against both the published schema and the compiler.

This is one unblinded authoring smoke sample, not a comparative quality evaluation. It demonstrates that the new constructs can be authored together. It is still verbose and recommends every top-level option; schema validity does not establish conversational usefulness or good prioritization. The older comparison artifacts assess earlier guidance and remain frozen separately.
